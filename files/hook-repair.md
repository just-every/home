The provided fleet installer symlinked common hooks into .git/fleet-cloud-hooks. Husky resolves its helper and repository hooks relative to $0, so pre-commit and pre-push failed trying to read fleet-cloud-hooks/h. The first commit did not exist and the first push was blocked by that local hook (no HTTP status supplied). The shell had not used fail-fast and continued after the commit failure; the retry uses set -e. Replaced only the clone-local hook symlinks with delegates that exec the exact preserved original hook path. The fleet commit-msg cleanup and repository hooks remain active. No product implementation, hook, or check was weakened or bypassed. The initial guard bundle contains only the unchanged main head and is not a product candidate.
