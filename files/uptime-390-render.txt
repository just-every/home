Uptime watches your websites and APIs on a schedule and tells you only when a failure is confirmed. It never calls a missing check healthy, and it keeps the evidence behind every incident. Alerts go to email, Slack or a signed webhook.

What it does
Check web pages and API responses for the right status, text, headers, data values and speed
Check that a server port answers, that DNS records are right, and that SSL certificates and domain registrations are not about to expire
Choose how many failed checks in a row open an incident and how many passes close it
Show a time as Unknown when no check arrived, instead of guessing it was fine
Watch cron jobs and nightly backups through heartbeat check-ins
Alert you by email, Slack or a signed webhook, and run an alert drill to learn whether a message really reaches someone
Pause alerts during planned maintenance windows
Run checks from a machine on your own network and export your monitors, evidence and alert history any time
What it promises
One failed check never raises an alarm. A monitor is called Failing only after confirmation, a missing check shows as Unknown, and it recovers only on fresh passing checks.
Every scheduled check and every retry is kept with its time, result and error type, and a retry never erases an earlier failure.
Only confirmed incident changes send automatic alerts, and a test send never changes a monitor's status.
Planned and recurring maintenance windows use US time zones and daylight saving, and keep the underlying check results so reports still show what happened.
Each alert gets one automatic send per destination where a repeat could double up, an unclear outcome is not sent again, and 'accepted' is never reported as 'read'.
An alert drill sends a clearly marked test with a one-time confirmation link, and a confirmation is the recipient's own report, never proof of monitoring.
Certificate checks look at trust, host name and expiry from each location, warn in stages before a certificate runs out, and clear only after a new valid certificate is seen.
A backup restores only into an empty installation: monitors come back paused, destinations disabled and old alerts held back.
Every address and redirect is validated, unsafe addresses are refused, and a redirect that downgrades from HTTPS is rejected.
An owner can erase a monitor with its evidence, an alert destination, or an operator, and gets a receipt of what was removed.
